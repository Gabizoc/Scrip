Face à ces accusations, le roi se révolte contre la reine.
Il s'agit d'un procès politique.

Les accusations sont :
- adultère
- empoisonnement
- inceste

Les preuves :
- témoignages
- lettres
- objets

Les accusateurs :
- le peuple
- les protestants
- les catholiques

Les conséquences :
- la reine est emprisonnée
- le roi se remarie
- la reine est exécutée

Les causes :
- rivalité politique
- jalousie
- vengeance

Les acteurs :
- le roi
- la reine
- les accusateurs
- les témoins
- les juges

Les lieux :
- le château
- la prison
- la salle d'audience

Les dates :
- 1559 : début des accusations
- 1560 : procès
- 1561 : exécution

Les enjeux :
- pouvoir
- légitimité
- réputation

Les thèmes :
- justice
- morale
- politique

Les questions :
- la reine est-elle coupable ?
- le roi est-il innocent ?
- les accusateurs sont-ils crédibles ?
- les témoins sont-ils fiables ?
- les juges sont-ils impartiaux ?

Les réponses :
- la reine est probablement innocente
- le roi est probablement coupable
- les accusateurs sont probablement motivés par des intérêts politiques
- les témoins sont probablement influencés
- les juges sont probablement biaisés

Les leçons :
- la justice est subjective
- la vérité est difficile à établir
- le pouvoir corrompt
- la jalousie détruit
- la vengeance est aveugle
